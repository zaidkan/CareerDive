# Local font assets

These are the exact WOFF2 files served by the previous Google Fonts stylesheet, downloaded on October 11, 2026. The local stylesheet preserves its faces, Unicode subsets, styles, weights, and font-display behavior. No visitor font requests leave the site.

Families: DM Sans, IBM Plex Mono, Plus Jakarta Sans, and Syne. Each family is distributed under the SIL Open Font License 1.1; the original license files are included here. `sources.json` records upstream URLs, sizes, and SHA-256 hashes.
