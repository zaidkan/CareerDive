## Decisions formerly left to product/architect — status 2026-09-22

**Resolved** (authoritative: [handoff](DESK_OS_AUDIT_HANDOFF.md) + [overhaul plan](DESK_OS_OVERHAUL_PLAN.md)): window ops and simultaneous-window count (cap 4); desk-only availability (**removed as product mode**); list mode as peer product (**removed after migration**); login/reopen persistence (lock = presentation over preserved session); scratch/file/document roles; allowed internal websites (internal-only); onboarding/Morgan sequencing (first successful workstation login, session-scoped); performance target class (Chromebook-class + measurable criteria).

**Still open** (do not treat as decided by this matrix): long-term no-WebGL presentation shape after device data; browser tabs beyond v1; corner resize; durable OS-local resume across full page refresh (G30); G24 query submit wiring; G25 content/task migration depth; any future bridge of cosmetic files into canonical evidence (G13 remains a boundary, not a silent goal).

Existing specification targets (boot-like immersion, deeper tools, communication and ticket lifecycle) must be reconciled with current partial content migration. This matrix does not authorize a second career, multiplayer, recommendation ranking, school deployment, hidden-state exposure or client-owned simulation rules.

**Supersession note:** any older reading of this matrix that required **Walk / Desk / List as equivalent peer product renderers** is superseded by G26’s RESOLVED row and the overhaul plan. Canonical/evidence/privacy constraints (G23, G27, G29 validation inside the single experience) remain in force.
