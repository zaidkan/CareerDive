## Decisions deliberately left to product/architect

Choose required window operations and simultaneous-window count; desk-only OS availability; login/reopen persistence; scratch/file/document roles; allowed internal websites; and onboarding message sequencing. Performance targets need specified devices/viewport and latency/frame expectations. None of these decisions is answered by decorative chrome or by adding a host filesystem.

Existing specification targets (boot-like immersion, deeper tools, communication and ticket lifecycle) must be reconciled with current partial content migration. This matrix does not authorize a second career, multiplayer, recommendation ranking, school deployment, hidden-state exposure or client-owned simulation rules.
